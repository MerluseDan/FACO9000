# SRDE-P5 — Portal Order Memory and Reverse-Path Instability

**Date locked:** 2026-11-03. **Concept originator:** Dan Merluse. **Project:** Blackbird Intelligence / Proto Alpha, Spatial Recursive Development Engine (SRDE).

**Status:** Original exploratory mathematical architecture, CPU-only controlled synthetic experiment; NOT human neural evidence, actual feelings, real-world forecasting, proof of unprecedented mathematics, or a new established theorem.

## Why this experiment is different

P1-P4 tested reachability, ordinary conditional-transition forecasting, and controls on historical time series. P5 changes the research object to **ordered portal paths** and the preservation of path order at depth 100 even when initial location is forgotten. Its reverse-path experiment tests limits of reconstructing the root from a deep endpoint. It does not repeat a climate or prior retrieval benchmark.

## Definitions, frozen before scoring

Local coordinates are `x in R^3`; valence input `F in [0,1]` is a *simulated numerical state input* (0 aversive, 1 rewarding in the conceptual convention), not observed human feeling. For this controlled experiment, F is held constant along each trajectory to isolate its effect on contraction. Let `a(F)=0.72+0.18 F`.

Two portals (A,B) use distinct anchors `u,v in R^3` and the maps `A(x)=a x+(1-a)u`; `B(x)=a x+(1-a)v`. A path labeled `AB` applies A then B; `BA` applies B then A. Each is repeated 50 times to reach **100 levels** with identical A/B counts. Positions are represented in a shared reference frame. No learned hidden coordinate chart, worker delegation, biological state or human semantic dataset is asserted.

The prespecified exact candidate relation is:

`x_AB(100) - x_BA(100) = (1-a^100)*(1-a)/(1+a)*(v-u)`.

The coefficient on the initial point in either final state is `a^100`. Both statements are algebraic identities for these specific maps, so a numerical match checks code, not empirical novelty.

## Hypotheses and disconfirmation conditions

- H1, ordering residue: with distinct anchors, normalized end-separation after 100 levels matches the formula within absolute `1e-11`. The matched **commuting null** `u=v` produces near-zero separation. Any mismatch is a numerical or coding failure, not a failed theory of cognition.
- H2, order information vs root information: across F=0,0.5,1, the path-order residual tends to a nonzero plateau, while `a^100` shrinks. This is a property of the specified contraction maps, not universal SRDE behavior.
- H3, reverse instability: with exact known portal maps but measurement noise, reversing 100 steps amplifies noise by approximately `a^(-100)`. Report both theory and observed error, including floating point sensitivity; do not imply actual historical causes are invertible.
- H4, synthetic event forecast: when the event is generated by the ordered 100-step dynamics, an oracle-known sequence-aware predictor should beat an **order-blind uncertainty-aware mixture** with the same anchors and F. A matched conventional closed-form sequence-aware predictor must tie SRDE. If order-blind wins or the closed-form method differs, flag failure. This is not a claim that SRDE beats standard sequence models.
- H5, orientation extension: two three-dimensional rotations about different axes have an order-dependent residual, while two rotations around the same axis commute within numerical precision. This is a diagnostic for a potential future local-chart operator, not a new mathematical finding.

## Predeclared simulation and metrics

- Python 3.10+ with numpy/scipy; CPU only; `seed=20261103`. Generate **4096 independently seeded synthetic worlds** with random `x0,u,v,w` (standard normal coordinates and normalized event direction `w`) and F in {0,0.5,1} sampled uniformly. Reject and redraw anchors where `||v-u||<0.05`.
- Portal order `AB` or `BA` chosen with equal probability. Generate the endpoint along the chosen path, then add a scalar measurement error `eps~N(0,0.04^2)` *in the event projection*, and label `y=1[dot(w, x_endpoint)+eps > 0]`.
- Forecasts: ordered portal **and identical conventional closed form** `Phi(dot(w,x_ordered)/0.04)`; order-blind mixture average of `Phi` for AB and BA; root-only `Phi(dot(w,a^100*x0)/0.04)`; intentionally incorrect order swapped. Compare Brier, log-loss and accuracy; test independent worlds, not duplicate votes.
- Primary score: `Brier(ordered)-Brier(unordered)` on all 4096 worlds. Paired 95% percentile bootstrap of worlds, 2000 replicates, `seed=20261104`. Declare a synthetic improvement only if 95% upper bound below 0; not general predictive validation.
- Further diagnostics: exact forward identity on 4096 worlds; fixed-F solutions for 0,.5,1; commuting `u=v` null; reverse error with 256 worlds for each F and independent Gaussian 3D endpoint noise sigma `1e-4`; 1024 cross-axis 3D rotation checks with independent random angles.
- Source/event generation and scoring use only fixed, explicit equations. No hyperparameter search or after-the-fact threshold tuning. All negative and null outcomes must be retained.
