# P9A Real Git Revision Pilot

Retrospective analysis of six authentic public Git documentation corrections in five repositories. Exact original Git blob hashes and commit URLs are recorded; original full documents are not redistributed.

Key result: P8-style exact-line matching found 3/5 manually assessed meaningful changes; five-line context matching flagged all 5 but produced 1 review alert for a still-supported claim. **Exploratory, selected, and not independent semantic validation.**

Run `python audit_receipts.py` to reproduce the confusion tables. Read `REPORT.md` for all scientific limitations.
