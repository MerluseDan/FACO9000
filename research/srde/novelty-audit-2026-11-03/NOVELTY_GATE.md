# SRDE literature and novelty gate

Owner instruction: 3 November 2026. Research related studies first; each new discovery experiment must ask a documented, materially distinct question.

Before freezing a new experiment:
1. Search the problem, mechanism and evaluation setting using established terminology as well as SRDE terms. Follow references/citations of the closest papers and check recent work. Search our existing experiment register for duplicates.
2. Record dated queries, primary source links, version/date, read scope, known closest studies and unresolved access gaps. Search absence is not proof of global absence.
3. Compare target, information available at decision time, acquisition/intervention actions, assumptions, data process, temporal setting, budget and primary estimand. Explain the exact difference and why it could change a scientific conclusion.
4. Reject a new name, new random seed, more recursion, another threshold, or equivalent iterative/recursive code as sufficient originality. A changed dataset is a robustness/application study unless it addresses a justified new setting. A combination is not automatically novel.
5. Use an operationally different method or a justified unexplored interaction/identifiability question. Name the closest conventional implementation. If the algorithms are equivalent, label the run an equivalence/control test.
6. Select applicable literature baselines, keep observations/budgets fair, charge metadata/audit costs, freeze split hashes and estimand, preserve negative and null outcomes. Do not retrofit novelty after seeing results.
7. Assign a status: REPLICATION/CONTROL, EXTENSION WITH DOCUMENTED DELTA, CANDIDATE NOT CLEARED, or NOVELTY CLAIM NOT SUPPORTED. Only a documented extension proceeds as a new discovery study. Replications remain necessary controls and must be labeled honestly.
8. Recheck literature before each new protocol and before publication. If a collision appears, retain the old protocol/results and issue a dated correction or redesign. Never guarantee first-ever status from a bounded search.

Required record fields: experiment_id, date, exact_question, closest_studies, internal_comparators, material_delta, scientific_reason, observable_inputs, actions_and_costs, primary_estimand, controls, literature_queries, source_read_scope, unresolved_gaps, novelty_status, freeze_hashes.

This is project guidance in the repository. It does not assert a globally installed enforcement hook or account-memory update.
